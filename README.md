# Virtual Venue Baseball Components - Assets

This repository contains shared assets for Virtual Venue Baseball Components (VVBC). It is an independent package distributed separately from the `org.vvbc.core` package.

The package targets Unity 2022.3. During development, use it in the shared Unity project in [Aoinu/vvbc](https://github.com/Aoinu/vvbc) as the `Packages/org.vvbc.assets` Git submodule. The Unity project, ProjectSettings, VRChat SDK, and Sandbox Scene are maintained in `Aoinu/vvbc`.

The initial package version is `0.0.1`.

## Getting the development project

Clone VVBC and its package submodules together:

```bash
git clone --recurse-submodules https://github.com/Aoinu/vvbc.git
```

For an existing clone, initialize and update its submodules:

```bash
git submodule update --init --recursive
```
